# Contributing

Open an issue for substantial work. Branch from `main` using `feature/*`,
`fix/*`, `docs/*`, or `chore/*`. Install with `pip install -e ".[dev]"`,
then run `ruff check .`, `mypy src`, and `pytest`.

Use Conventional Commits: feat, fix, docs, test, refactor, perf, build, ci, chore,
or security. Never commit proprietary reports, secrets, personal data, or indexes.
Contributions are licensed under MIT.
